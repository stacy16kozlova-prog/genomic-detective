# 🧬 Genomic Detective

**Система приоритизации генетических вариантов для поиска причин редких наследственных заболеваний**

Проект разработан для хакатона ХИМБИО-ХАКАТОН СИНТЕЗ 2026 (Кейс №3).

🔗 **Живое приложение:** https://genomic-detective-rymkyjefowxhikyu4hjg9m.streamlit.app/

---

## Задача

Разработать систему, которая принимает описание клинического случая и набор генетических вариантов, анализирует их, сопоставляет с фенотипом пациента и формирует ранжированный список генов-кандидатов, наиболее вероятно связанных с заболеванием.

---

## Ключевые возможности

### 1. Фенотипический матчинг (HPO)
Система сопоставляет симптомы пациента (в формате HPO-термов) с базой знаний генов и выдаёт ТОП-3 кандидата с объяснением, почему каждый из них важен.

### 2. Честная неопределённость (Сценарий 3)
В отличие от большинства решений, система **не ставит диагноз** при недостатке данных. Она описывает ограничения и даёт конкретные рекомендации (WGS, секвенирование трио, МРТ).

### 3. Разделение доказательств
Каждый кандидат сопровождается тремя категориями:
- 🟢 **Факты** — подтверждённые сведения из баз данных (OMIM, ClinVar, Orphanet)
- 🟡 **Вычислительные прогнозы** — CADD, gnomAD AF
- 🔵 **Гипотезы системы** — фенотипический overlap

### 4. Интерактивная песочница
Врач может добавить новый HPO-терм и увидеть, как пересчитывается рейтинг кандидатов в реальном времени.


### Формула Composite Score
Score = Факт (до 50) + Фенотип (до 30) + Генотип (до 10) = максимум 90/100


| Компонент | Максимум | Описание |
|-----------|----------|----------|
| 🟢 Факт из базы знаний | 50 | Ген совпал с KNOWLEDGE_BASE |
| 🔵 Фенотипический overlap | 30 | `30 × (совпавшие HPO / всего HPO)` |
| 🧬 Генотип | 10 | Гомозиготный (1/1) = +10, гетеро (0/1) = +5 |

Резерв в 10 баллов оставлен для интеграции с ClinVar API.

## Библиотеки и программы

- **Python 3.10+**
- **Streamlit** — веб-интерфейс
- **Pandas** — обработка табличных данных
- **JSON** — парсинг фенотипа (формат GA4GH Phenopacket)
- **HPO Ontology** — стандартизированные медицинские термины

### Внешние базы данных (архитектурно заложены)

| База | Назначение | Статус |
|------|------------|--------|
| OMIM | Ассоциации ген-болезнь | ✅ В KNOWLEDGE_BASE |
| Orphanet | Редкие заболевания | ✅ В KNOWLEDGE_BASE |
| ClinVar | Клиническая значимость | ⚠️ Эмулируется |
| gnomAD | Популяционные частоты | ⚠️ Эмулируется |
| Ensembl VEP | Аннотация вариантов | ⚠️ Функция готова |
| Phenopacket Store | Клинические случаи | ✅ Источник данных |
